# cook852.github.io

Hong Kong home-style Chinese recipe site built with Docusaurus (zh-Hant). See `README.md` for commands and the recipe format.

## Slugs, tags and links: English only, no Mandarin pinyin

Every machine-readable name must be plain English: lowercase letters, digits and `-`.

- **Covers:** recipe filenames, category folder names, `link.slug` in `_category_.json`, `slug`/`id` in frontmatter, tag keys and `permalink` in `recipes/tags.yml`, and any URL path or internal link.
- **Never use Mandarin pinyin**, e.g. `jia-chang`, `fan-qie-chao-dan` or `ji-dan`. Don't use Cantonese romanization either, e.g. `lo-bak-pai-gwat-tong`.
- **Use English names instead**, e.g. `home-style`, `soup`, `dim-sum`, `tomato-scrambled-eggs` and `egg`.
- **Chinese goes only in human-readable fields**, such as `title`, `label` and `description`.
